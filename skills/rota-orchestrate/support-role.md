# Support role

Loaded by `skills/rota-orchestrate/SKILL.md` (section *Support role*) when `round.role: support` is set on this machine.

A second machine can run rounds beside main without any link between them (`round.support` names it, `round.role: support` is set locally per machine; see `docs/contributing/rounds.md`). On a support machine you never merge and never write tracked `.rota/` content: those verbs exit 4 `blockedBy: role`. Workers there post learnings as `learning` comments (`rota item comment add <ID> --kind learning`), skip the contract-doc restamp, and leave knowledge to main, which runs `/rota-learn` at wind-down and harvests them. Set `round.support` between rounds: bounce counts are not carried over when the key flips. At the bounce cap the item parks `needs-human` and no review-bounce is posted.

Support fills its slots from issues pinned to it, then unpinned issues within its configured `round.scope`. There is no cross-machine slate reservation: the shared claim decides the winner. A support assignment pins an unpinned issue after winning its claim, so the support queue, main's watch and the gate can track it; a pre-dispatch rollback removes only the pin that assignment added. `round support offer` is optional steering.

Round trip with main (full rules in `docs/contributing/rounds.md`): hand a support issue back at once with `rota round support return <ID> --reason-file <f>` when it cannot be worked, never idle on it. The issue thread is the index: notes go on the issue as `--kind feedback` comments, a relayed instruction as `--kind relay` (`rota item comment add <ID> --kind feedback|relay`), and bounce, pick and the review relay leave a pointer comment there. Main's `round watch` wakes on a support PR head change, a PR opened for an issue pinned `machine:<round.support>` and a support comment; the support watch wakes on main's comments on held issues. A relay you send is also an issue comment, which main's gate reads for provenance; an explicit offer comment is the assignment approval when main offered the issue. An automatically claimed issue has no offer approval to cite. Workers never post `--kind relay`.
