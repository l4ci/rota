**Workflows and skills** for one agent at a time:

- [GSD](gsd.md): spec-driven phases from discuss to ship
- [Superpowers](superpowers.md): a skills methodology for many harnesses
- [OpenSpec](openspec.md): living specs and delta change folders
- [ralph](ralph.md): a fresh-context loop over a `prd.json`

**Parallel agents** in worktrees:

- [Conductor](conductor.md): a Mac app for agents in workspaces
- [Orca](orca.md): a desktop app for fleets of agents
- [Vibe Kanban](vibe-kanban.md): a kanban board that runs agents
- [Claude Squad](claude-squad.md): a TUI for agents in tmux sessions

**Orchestrators** with a coordinating agent:

- [Gas Town](gastown.md): a Mayor, polecats and a merge queue
- [Octo](octo.md): several AI providers on one question
