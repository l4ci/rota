Maintainer feedback (round 1, 2026-10-04): starting herdr, then claude, then typing /rota-orchestrate is no better than hv-skills. rota already launches worker sessions (round assign: tab, account, brief); the orchestrator gets nothing.

## Proposal
- `rota orchestrate` (name open): run `rota doctor`, fail fast on `fail`.
- Inside herdr/tmux: open an orchestrator tab. Outside: exec herdr (or tmux) with that tab as startup command. No multiplexer: run the agent in place (solo).
- Launch the configured agent (claude or codex) under `rota keepalive run`, with the first prompt as a CLI argument (`claude "/rota-orchestrate"`, codex equivalent): no pane typing.
- Does not run `round start`; slate choice stays in the skill.

## Acceptance
- [ ] One command from a plain shell ends in a live orchestrator session that has started /rota-orchestrate
- [ ] Works inside herdr, inside tmux, and outside both; agent kind from config
- [ ] Doctor failures stop it before any session starts
- [ ] Contract entry, tests, docs/usage/parallel-rounds.md "Your first round" leads with it
