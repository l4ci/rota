# T01: Avoid `&` in TodoWrite task titles (Claude Code TUI renders `&amp;`)

> Related TODO entry: `[T01]` in `.hv/BACKLOG.md`

## Summary

Claude Code TUI does not HTML-decode task titles passed to TodoWrite — strings containing `&` render as the raw entity `&amp;`. Upstream bug in Claude Code; we cannot fix it. The hv-skills-side action is (a) document the workaround in any skill that emits TodoWrite items, and (b) sweep existing skill prompts/templates for `&` in suggested task titles, replacing with "and" or "+".

## Detail

### Observed rendering

```
Dispatch &amp; verify wave… (6m 15s · ↓ 26.0k tokens · almost done thinking)
  ⎿  ◼ Dispatch &amp; verify wave
     ◻ Commit + TODO + smoke
     ◻ Merge &amp; report
     ✔ Preflight &amp; guard
     ✔ Register status &amp; branch
      … +1 completed
```

Spotted in a `/hv-work` session. Task titles "Dispatch & verify wave" and "Merge & report" render with the literal `&amp;` sequence instead of `&`. The "+" character ("Commit + TODO + smoke") renders correctly — confirming the bug is specific to `&` / HTML-entity encoding, not punctuation generally.

### Root cause (upstream)

Claude Code's TUI task renderer treats the title string as HTML and escapes `&` to `&amp;` before display, but never decodes on render. Not something hv-skills controls.

### Workaround (our side)

Avoid `&` in any task title emitted via TodoWrite from hv-* skills. Replace with:
- "and" — for prose-style titles ("Dispatch and verify wave", "Merge and report")
- "+" — for compact list-style titles ("Commit + TODO + smoke")

### Scope of sweep

Files to grep for `TodoWrite` / `TaskCreate` payloads containing `&`:
- `hv-*/SKILL.md` — instructional examples and templates
- `references/*.md` — any shared phase-table templates that get copied into TaskCreate calls
- `bin/` — any helper that synthesizes task titles (low likelihood but worth checking)

### Acceptance

- No hv-* skill emits a TaskCreate / TodoWrite title containing `&`
- A short note in `references/authoring-conventions.md` (or equivalent) telling future skill authors: *don't use `&` in task titles — Claude Code TUI renders it as `&amp;`. Use "and" or "+" instead.*
