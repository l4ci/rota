## What happened
Topic args must be the complete `## ` heading text (e.g. `Build & Tooling: Smoke testing`); a partial name like `Smoke testing` silently returns empty with exit 0. Callers building relevance briefs (including /hv-next subagent prompts) must copy topic names verbatim from the CLAUDE.md index — an empty result is indistinguishable from 'no learnings exist'.

## Expected
Partial topic names should either substring-match against headings or exit non-zero / warn on stderr, so a mistyped or shortened topic is distinguishable from a topic with no learnings.
