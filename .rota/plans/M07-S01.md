# M07-S01 — Backend seam, FileBackend, tracker-call wrapper, config keys

## Goal

Every backlog read/write and every gh/glab call goes through one seam each, with the file backend byte-identical to today, so S02 can plug in the GitHub and GitLab adapters.

## Approach

Pure code move, not a rewrite: the verbs the issue backend will need are lifted out of helpers into `FileBackend` in new `bin/hvlib_backend.py`, and helpers become thin `get_backend()` callers. File-only helpers stay put and gain a guard that refuses in issue mode. Until S02, `backlog.backend: "issues"` exits 2 with "issues backend not available yet (M07-S02)" — never a half-working mode. A new `bin/hv-tracker-call` becomes the only place gh/glab is invoked, and the existing issue helpers move onto it. The existing smoke suite plus golden fixtures prove nothing changed. Waves: T1 ∥ T4, then T2, then T3 ∥ T5.

## Tasks

- **T1** — Config keys + accessors. `hv-config show` lists `backlog.backend` (default `file`), `issues.provider` (`auto`), `issues.labels.{inProgress,needsReview,changesRequested,released,notPlanned,milestoneTracker,types.bug,types.feature,types.task,priorityPrefix}`; `tracker_label(cfg, "inProgress")` falls back to legacy `issues.label` when `labels.inProgress` is unset; `backlog_backend(cfg)` rejects unknown values. Rows are `required=False` so existing configs don't go STALE.
  - Files: `bin/hvlib_config.py`, `bin/hvlib.py`, `test/sections/44_hvlib_exports.sh`, `docs/reference/config-options.md`, `docs/usage/configuration.md`, new `test/sections/55_backend.sh`
  - Verify: 53 asserts show values/sources, the alias fallback, and bogus-backend rejection; `hv-config-schema-check` still passes on this repo.

- **T2** — `FileBackend` create/read. `hv-append`, `hv-todo-field`, `hv-todo-set-field`, `hv-backlog` call `get_backend()`; logic moves into `FileBackend.append / fields / set_field / list_open`. With `issues` they exit 2 with the not-available message and leave files untouched.
  - Files: new `bin/hvlib_backend.py`; the 4 helpers; `bin/hvlib.py`; `test/sections/44_hvlib_exports.sh`; `test/sections/55_backend.sh`
  - Verify: golden check in 53 (each helper on a fixture, stdout + file bytes equal to pre-change capture); existing sections using these helpers pass; refusal tested.

- **T3** — `FileBackend` lifecycle + file-only guards. `hv-complete` / `hv-uncomplete` go through `FileBackend.complete / uncomplete` (proof gate, close reasons, counter bump unchanged). `hv-next-id`, `hv-rm`, `hv-archive-old`, `hv-backfill-since`, `hv-todo-drift` refuse in issue mode with a pointer to the tracker equivalent.
  - Files: those 7 helpers; `bin/hvlib_backend.py`; `test/sections/55_backend.sh`
  - Verify: sections `52_proof`, `35_undo`, `07_refactor` pass unchanged; 53 asserts each refusal message.

- **T4** — `bin/hv-tracker-call` wrapper. `hv-tracker-call [--provider auto|github|gitlab] -- <args>` runs gh/glab; provider from `issues.provider`, else `hv-issues-provider`. Injects `--limit 1000` on list calls without one and `--paginate` on `api` calls; warns when a result hits the limit. Primary-limit 429 → one bounded wait (`issues.retryWaitSeconds`, default 60) and one retry; secondary-limit 403 → immediate exit 4 with a one-line report, never a loop; missing/unauthed CLI → exit 3.
  - Files: `bin/hv-tracker-call`, `bin/hvlib_config.py` (retry key), `docs/reference/cli-helpers.md`, new `test/sections/54_tracker_call.sh`
  - Verify: 54 puts fake `gh` / `glab` on PATH recording argv and emitting canned errors; asserts limit/paginate injection, single retry, hard stop exit 4, exit 3 when missing.

- **T5** — Existing issue helpers onto the wrapper. `hv-issues-list`, `hv-issues-close`, `hv-issues-label`, `hv-issues-imported`, `hv-pr`, `hv-issue-suggest` reach gh/glab only via `hv-tracker-call`, output unchanged; `hv-issues-imported --open-only` still no-ops gracefully without a CLI.
  - Files: those 6 helpers
  - Verify: `git grep -nE '(^|[^-])\b(gh|glab) (issue|pr|mr|api|label|auth)' bin/ ':!bin/hv-tracker-call'` is empty; sections `34_issues`, `19_issue_release` pass; full `bash test/smoke.sh` passes at slice end.

## Open questions

- `glab issue list` pagination on glab 1.120: `--per-page` / `--page`, or `glab api --paginate`? Check at T4 start.
- Not-available refusal uses exit 2 now; S02 removes it.

## Assumptions

- No cross-process write pacing in S01; bulk pacing (sleep between creates) belongs to S07 migrate — one skill run is far under GitHub's limits.
- `FileBackend` is a pure move; existing smoke + golden fixtures are the byte-identical oracle.
- Helpers import through the `hvlib` shim per the re-export convention, so `44_hvlib_exports` stays authoritative.
- File-only for now: `hv-issues-imported`, `hv-undo`, `hv-summary` (read; moves in S02), plus the guarded verbs in T3; their issue-mode behaviour is settled in S02/S03.
- `hv-pr` is gh-only today; the GitLab MR path lands in S03.
