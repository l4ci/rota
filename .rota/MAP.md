# Project map

AI-facing index of rota's subsystems, mapped at `a27543a2`. Detail files live in `.rota/map/<name>.md` and load on demand with `rota map query <name>`. The thin always-on summary in `AGENTS.md` is regenerated by `rota map index`.

Refresh with `/rota-refactor --map`. `rota map stats` warns when a file falls behind `map.staleCommits`.
