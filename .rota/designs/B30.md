# B30 — summary "Recent" shows the oldest completions

`rota summary` (internal/cli/a4b.go around :500-540) builds Recent from the first three Done lines of `## Completed`; completions append at the end, so it shows the oldest. Seen live 2026-10-04: F84/T122 completed today, Recent still shows three 2026-10-01 items.

## Approach
- Fix the reader, not the writer: pick the three newest Done lines by date; on equal dates, later in the file is newer. Do not change where `item complete` inserts (keeps BACKLOG diffs stable).
- Issue mode already renders newest first; it must not change.
- If a frozen record changes, update it with `-update-frozen` and say why in the PR.
