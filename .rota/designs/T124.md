# T124 — knowledge replace verb and milestone overview setter

Stale hv-skills wording in tracked `.rota/` can't be fixed by any verb: `knowledge amend` only appends, `rename-topic` only renames, `milestone put` replaces a milestone body but not the MILESTONES.md overview.

## Ordering
Merges after T123 (verb contract split). Contract entries go in the new `docs/design/contract/` group file for knowledge / milestones, not the old single file.

## Approach
- `rota knowledge replace <topic> <old> <new>`: exact-substring replace of one bullet in one topic; refuse (exit 4) when <old> matches zero or more than one bullet; `changed` false when old==new. Exact naming/flags are the worker's call, stated as unratified.
- A milestone overview setter (e.g. `rota milestone overview --body-file`), replacing only the overview paragraph(s) above `## Active milestones`.
- Each new verb: contract entry, Go tests, smoke section (number assigned in dispatch), and the skill prose that should mention it.
- Then use the verbs to fix `.rota/MILESTONES.md:3` and the `/hv-*` / `.hv/` wording at `.rota/KNOWLEDGE.md:74,76`. Other `.hv/` mentions (ARCHIVE, BACKLOG, DECISIONS, item files) are history and stay.

## Acceptance
- [ ] `rota knowledge replace` exists with contract entry, tests, and refuses ambiguous/missing matches
- [ ] Milestone overview setter exists with contract entry and tests
- [ ] MILESTONES.md overview and KNOWLEDGE.md lines fixed through the new verbs (commit shows verb output, not hand edits)
- [ ] Full gate green
