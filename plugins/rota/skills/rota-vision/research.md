# Step 4 — Research (opt-in)

Ask first: *"Run web research on this? (yes / skip)"*. On yes, split the framing into 3-5 independent angles, run one `standard` subagent per angle in a single batch (`WebSearch` / `WebFetch`), and merge to 3-5 actionable findings. Prefer primary sources (official docs, specs, the project's own repo), cite one source per finding, and label a secondary source (blog, forum, summary) as such. If nothing useful comes back, say so and move on. Keep any finding that contradicts the user's framing for Step 5.
