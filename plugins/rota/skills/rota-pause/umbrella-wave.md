# Umbrella wave pauses

## Step 2

Several matches: run `rota repo which`. Exit 0: the user `cd`-ed into one sub-repo; pause only that entry. Exit 3 (umbrella root): pause all matches as one wave. Do not ask which repo.

## Step 4

In a wave, only `Repo:` and the Uncommitted artifact differ; keep separate files so one repo can be abandoned while others resume.
